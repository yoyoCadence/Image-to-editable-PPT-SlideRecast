# Rights and licensing gate

Intended future project license: Apache-2.0. **No Apache project LICENSE is granted in this alpha working tree.** `package.json` is private and UNLICENSED, and plugin.json intentionally omits a license claim. Public GitHub visibility by itself does not confer an open-source license.

The maintainer requested independent development. All authored helper logic, workflows, documents, examples and branding started in this repository on 2026-10-13. No prior private implementation was read or ported. Publicly licensed library bundles and API declarations are explicitly third-party code, not an independence claim about those packages. Their actual versions and notices are recorded.

Bundled package licenses reviewed: MIT, ISC, MIT-or-GPL (MIT selected for JSZip), and MIT plus zlib-derived pako terms. Preserve full upstream notices and copyright. Office Kit's own third-party notices are also included. Dependencies not redistributed (Preview/Sharp/native binaries, LibreOffice/Poppler, test fonts, Python QA libraries) still have their own licenses. Skill Python helpers use pypdf and Pillow or external programs; PyMuPDF remains developer-only and requires review if a later release distributes or incorporates it.

Before formally adding LICENSE or publishing a release, the maintainer must confirm ownership/authorization of the newly authored work and check applicable employment agreements, job-related work rules, confidentiality obligations and trademark/branding constraints. Independent implementation and personal equipment do not automatically remove contractual or work-for-hire issues. This record does not assert absence of legal risk or replace legal advice.

Release checks are in RELEASE-CHECKLIST.md. No public directory submission or formal release occurred during this kickoff. The initial attempt to push source to the user-created public repository was blocked by automatic approval review; the local commits and reviewable candidate artifacts are retained pending explicit confirmation.
