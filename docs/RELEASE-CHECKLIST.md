- [ ] Add the final Apache-2.0 LICENSE only after confirmation.
- [ ] Upload the Claude ZIP in an authenticated account and verify acceptance, case spelling and actual ZIP limits.
- [ ] Run image and multipage-PDF conversions in Claude.ai without local installations; record model/runtime, prompts, outputs, elapsed time and observable usage.
- [ ] Repeat with representative unseen sources including dense Chinese text, curves, tables and mixed page sizes.
- [ ] Select/change native objects in LibreOffice Impress; record actual UI results.
- [ ] Check original PPTX in Microsoft PowerPoint for the web; record fonts/effects/rendering limitations. Do not replace originals with application saves.
- [ ] Validate full Open XML schemas if claiming schema compliance; current inventory checks are limited.
- [ ] Test maintainer Windows developer workflow on personal equipment.
- [ ] Confirm public GitHub push authorization and open the prepared PR.
- [ ] Verify OpenAI publisher identity, role, package uploader checks and skill scans.
- [ ] Get maintainer confirmation before directory submission, official release or public promotion.
